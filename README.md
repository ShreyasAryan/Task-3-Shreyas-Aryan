# Project 3 – SQL Data Analysis

## Files
- `sales_analysis.db` – SQLite database
- `sales_data.csv` – source dataset
- `project_3_queries.sql` – 20 SQL analysis queries
- `run_sql_analysis.py` – Python runner for important SQL queries
- `SQL_Analysis_Results.xlsx` – query results in Excel
- `PROJECT_REPORT.md` – complete project report
- `requirements.txt` – Python dependencies

## Run
```bash
pip install -r requirements.txt
python run_sql_analysis.py
```

You can also open `sales_analysis.db` using DB Browser for SQLite and run the SQL queries directly.
